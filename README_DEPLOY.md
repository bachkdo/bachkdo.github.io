# Bach Do website build

This folder contains a first-pass rebuild of your GitHub Pages site based on the layout style of the reference site you shared.

## Files
- `index.html` — homepage
- `research.html` — research page
- `publications.html` — publications page
- `style.css` — shared styling
- `images/profile-placeholder.svg` — temporary profile image

## Fastest way to use it
1. Replace the files at the root of your repo with these HTML files and `style.css`.
2. Upload `images/profile-placeholder.svg` into an `images/` folder in the repo.
3. Replace the placeholder profile image with your real headshot when ready.
4. Add your CV PDF and uncomment the CV icon in `index.html`.
5. Review the publication list and add anything missing.

## Notes
- I built this as plain static HTML/CSS so it is easy to maintain on GitHub Pages.
- You do not need to keep the current blog-style Jekyll theme for this version.
- If you want, you can later add more assets such as `images/profile.jpg`, publication thumbnails, or a downloadable CV.
